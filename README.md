# Stella

Stella lets you play games from your Steam library in SteamOS on an Apple silicon Mac running macOS 15 or later. Stella is a fork of [FX Steam Launcher](https://github.com/fxgl/steamac).

Download the [latest Apple Silicon DMG](https://github.com/Ralsei-x64/Stella/releases/download/continuous/Stella-arm64.dmg).
